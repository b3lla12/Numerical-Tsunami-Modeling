# 🌊 Numerical Tsunami Modeling Using COMCOT v1.7

## 📍 Study Area

Riting Beach, Aceh, Indonesia

---

## 📖 Project Overview

This project reconstructs the 2004 Aceh tsunami using COMCOT v1.7.

The research estimates:

- Maximum tsunami wave height
- Estimated Time of Arrival (ETA)
- Bathymetric influence on tsunami propagation

---
